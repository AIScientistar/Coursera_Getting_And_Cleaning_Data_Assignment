# Getting and Cleaning Data - Coursera course project

## Project Brief
As a part of the course, the purpose of the project is to describe the sourced data, assign variables to read the data, any transformations to clean up and generate a tidy data set using R script.

## Repository files
1. 'CodeBook.md' - Describes how to source the data defined in the course work, information on the assigned variables and summary of the R script used to generate tidy data.
2. 'run_analysis.R' - Detailed information and the script used for performing the tasks prescribed as part of the coursework.
3. 'TidyDataSet.txt' - Final cleaned/tidied data using the above R script file.
